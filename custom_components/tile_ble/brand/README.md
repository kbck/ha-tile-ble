# Brand Asset

`icon.png`, `icon@2x.png`, `dark_icon.png`, and `dark_icon@2x.png` are the
Tile icons from Home Assistant's brands repository:
https://github.com/home-assistant/brands/tree/master/core_integrations/tile

The dark variants keep the logo visible on dark backgrounds. Both themes include
standard and high-resolution icons so HA can select the appropriate asset.

Tile branding belongs to its respective owner and is used only to identify the
supported hardware. This is an unofficial integration.
